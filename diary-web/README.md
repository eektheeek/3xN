# Diary Web

Мобильный PWA на Preact. Работает с [diary-api](../diary-api).

## Запуск

```bash
cd diary-web
npm install
```

`.env` (для iPhone в той же сети):

```
VITE_API_URL=http://192.168.x.x:8080
```

```bash
# терминал 1
cd diary-api && go run ./cmd/server

# терминал 2
cd diary-web && npm run dev
```

## Экраны

| Маршрут | Что делает |
|---------|------------|
| `/` | Список сохранённых тренировок |
| `/workouts/new` | Собрать тренировку: название + упражнения из каталога или новые |
| `/workouts/:id` | Состав тренировки → **Начать** |
| `/workouts/:id/start` | Записать подходы по всем упражнениям и сохранить |
| `/exercises/new` | Создать упражнение (возврат в сборку тренировки) |
| `/exercises/:id` | Задать цель (подходы / повторы / вес / резинка) |
